For a single-file download, use **Windows EXE** above. For the editable project, use **Source project ZIP**.

## Start

1. Open Settings and save the key for your chosen AI provider.
2. Choose a model and press **Start Listening**.
3. Capture a region with **Ctrl+Alt+S**. Answers appear in the overlay and copy automatically.

| Shortcut | Action |
| --- | --- |
| Alt+C | Open prompt |
| Esc+1 | Hide overlay |
| Esc+2 | Show last answer |
| Left / Right | Previous / next answer |
| Up / Down | Scroll answer |
| Ctrl+Alt+O | Open settings |

Hold Esc and press 1/2, or press them quickly in sequence. Numpad keys also work.
